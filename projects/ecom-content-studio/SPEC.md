# 项目开发交接文档：电商内容工作台（E-Com Content Studio）

## 1. 任务目标与定位
请从零构建一个高保真、纯前端运行的 Web 应用原型——**「电商内容工作台」**。
- **目标用户**：同时管理多个店铺、需要高频批量上新测款的电商运营人员。
- **核心价值**：输入商品基础信息与图片（支持单个录入或 CSV 批量导入），快速生成可编辑的「商品主图 + SEO 标题 + 核心卖点文案」，支持**基于 HTML5 Canvas 的真实主图实时合成与一键导出 PNG**，并可将好用方案沉淀为可复用模板。
- **运行约束**：纯前端架构，**零后端、零真实外部 API 依赖、断网可用**，所有自定义数据持久化至 `localStorage`，且首次打开即具备极佳的演示质感。

---

## 2. 技术栈与工程规范
- **框架与工具**：React 18 + TypeScript + Vite + Tailwind CSS + `lucide-react`（图标库）。
- **部署兼容性**：在 `vite.config.ts` 中配置 `base: './'`，确保构建产物可直接部署至 GitHub Pages 或任意静态托管平台且无资源路径报错。
- **视觉风格**：现代 B2B SaaS 工作台风格（浅灰画布底色 `#F8FAFC`、纯白卡片 `#FFFFFF`、克制的 Slate 边框、清晰的主次操作按钮与信息层级），适配桌面端（1280px 及以上优先，兼顾窄屏自适应）。
- **代码质量要求**：组件拆分清晰，状态逻辑与模拟生成引擎解耦，完成后必须执行 `npm run build` 确保 TypeScript 与 Vite 打包零报错。

## 3. 信息架构与页面设计（3 个主视图）

左侧固定侧边栏导航（220px 宽），包含应用名称、3 个视图切换入口，以及底部「重置示例数据」按钮：

### 视图 A：素材生成台（默认首页，核心工作流）
采用左中右三栏或上下分区的清晰工作台布局：

1. **顶部操作栏**：
   - 快捷按钮：**「一键加载示例批次（3款商品）」**、**「下载 CSV 导入模板」**、**「批量导入 CSV」**、**「新建空白商品」**。
   - 当前批次状态指示与「保存当前批次到历史」按钮。

2. **左侧：商品队列与录入区**：
   - **批量商品列表**：展示当前批次所有商品缩略图、名称、生成状态（未生成 / 生成中 / 已生成 / 已定稿），支持点击切换当前编辑的商品、删除商品。
   - **单个商品表单**（精简必填项，不强迫用户填长表）：
     - 必填项：商品名称、商品类目（如箱包配饰 / 服饰鞋靴 / 家居水具 / 数码配件）、商品图片上传（支持点击或拖拽上传 JPG/PNG/WebP，附格式与大小提示）。
     - 选填项（可折叠为「更多商品参数」）：材质、颜色/规格、目标人群、核心亮点关键词、大促利益点角标（如“限时直降”“买一送一”“新品首发”）。
   - **模板选择下拉框**：可选择「系统默认生成」或已保存的自定义模板。
   - **主操作按钮**：
     - 「生成当前商品素材」（单条生成）
     - 「批量生成全部商品」（顺序模拟生成队列中的所有商品）

3. **中间：实时主图合成画布（核心亮点功能）**：
   - 使用 **HTML5 Canvas** 实时渲染 `800×800`（标准 1:1 电商主图比例）高清预览图（页面内自适应缩放到约 `360×360` 显示，导出时按原始 `800×800` 像素输出）。
   - **画面构成**：背景底色/渐变装饰 + 用户商品图居中展示（保持宽高比 `contain` 居中，不拉伸变形） + 顶部或底部高对比度主标题 + 卖点标签胶囊 + 左上/右上角利益点角标。
   - **4 套一键切换的主图视觉模板**：
     1. `promo-red`（大促爆款红：红橙渐变边框 + 醒目黄字价格/利益角标）
     2. `minimal-white`（极简通勤白：浅灰留白 + 黑色利落衬线/无衬线排版）
     3. `luxury-black`（高端质感黑金：深炭黑底 + 香槟金细线边框与标题）
     4. `fresh-green`（清新种草绿：柔绿背景卡片 + 圆角手账风标签）
   - **微调控件**：允许直接在画布下方修改「主图大字短标题」「角标文案」，实时重绘 Canvas。
   - **导出按钮**：**「一键导出高清主图 PNG」**（直接触发浏览器下载 `{商品名称}-主图.png`）。

4. **右侧：生成文案编辑与资产沉淀区**：
   - **SEO 商品标题**：可实时编辑，带字数统计（标注电商常见 30 字上限提示）与「复制标题」按钮。
   - **核心卖点文案（3 条）**：每条支持行内修改、单条重新生成、删除或新增。
   - **底部快捷动作**：
     - 「一键复制全部文案」（复制到剪贴板并给出 Toast 成功提示）
     - 「重新生成文案」（支持换一版措辞风格）
     - **「存为复用模板」**（弹出轻量模态框，填写模板名称与标签，将当前主图视觉风格 + 标题结构 + 卖点风格保存到模板资产库）
     - 「标记为已定稿」

### 视图 B：模板资产库
- 顶部支持按标签筛选（如：全部、大促冲量、极简质感、通勤日用）和关键词搜索。
- 卡片网格展示所有已保存模板（含预设模板 + 用户新建模板），每张卡片显示：模板名称、视觉风格缩略色块预览、适用类目/标签、标题公式示例、卖点风格说明。
- 支持操作：**「应用到生成台」**（点击后自动切回生成台并选中该模板）、**「编辑模板信息」**、**「删除模板」**。

### 视图 C：历史批次 / 草稿箱
- 列表展示已保存的历史生成批次（批次名、创建时间、包含商品数、状态标签：待审核 / 已定稿）。
- 支持按状态筛选、**「重新打开编辑」**（恢复到素材生成台继续修改）、删除批次。

## 4. 核心引擎与技术避坑要求（务必严格遵守）

### 4.1 真实感模拟 AI 生成引擎（`src/utils/mockGenerator.ts`）
- 严禁返回死板的“示例标题 1 / 卖点 1”占位文本。
- 根据用户输入的 `name`、`category`、`material`、`color`、`audience`、`highlights` 以及所选 `template` 的风格倾向（大促型 / 极简型 / 种草型 / 专业参数型），动态拼装并变体化生成贴近真实淘宝/抖音运营语气的：
  1. 含高频搜索关键词的 SEO 商品标题（22–30 字）。
  2. 主图精炼短标题（6–12 字，适合大字排版）。
  3. 3 条不同切入角度的核心卖点（材质工艺 / 使用场景 / 情绪与性价比价值）。
- 每次点击生成时，模拟 `600ms–900ms` 的异步处理延迟，展示明确 Loading 状态，并在请求期间**禁用按钮防止重复点击**。

### 4.2 Canvas 主图渲染与 PNG 导出防坑（`src/utils/canvasRenderer.ts`）
- **零跨域污染（防 Tainted Canvas）**：
  - 3 个内置示例商品的商品图片，**禁止使用无 CORS 头的外部网络图床链接**！请为内置示例商品生成精美的**本地内联 SVG Data URL**（例如：极简矢量风格的通勤双肩包插画、防晒冲锋衣插画、磨砂保温咖啡杯插画），确保无需联网也能 100% 成功调用 `canvas.toDataURL('image/png')` 导出。
  - 用户上传图片统一通过 `FileReader.readAsDataURL` 转为 Data URL 后绘制。
- **中文自动换行**：实现健壮的 `drawWrappedText` 工具函数（按字符宽度逐字测量折行，超出最大行数自动截断加省略号），防止中文标题溢出画布边界。

### 4.3 CSV 批量导入与模板下载（`src/utils/csvHelper.ts`）
- 编写轻量、无多余重依赖的 CSV 解析与导出工具（支持带引号字段）。
- 「下载 CSV 导入模板」时，必须在文件开头加上 **UTF-8 BOM (`\uFEFF`)**，确保 Windows/Mac 版 Excel 双击打开中文表头不乱码。
- 表头字段：`商品名称,商品类目,材质,颜色规格,目标人群,核心卖点,角标文案`。
- 上传非 `.csv` 文件或解析为空时，给出友好的页面内联错误提示，且**绝不清空用户已有数据**。

### 4.4 关键容错与用户体验细节
1. **空白上手引导**：当队列为空时，在画布区域显示清晰引导卡片，提供「一键加载 3 款示例商品体验」主按钮。
2. **表单校验**：缺少商品名称等必填项时，在对应输入框下方标红提示，不要用浏览器原生 `alert()`。
3. **草稿自动保存**：当前工作台编辑内容、模板库、历史批次自动同步至 `localStorage`（带 `try/catch` 保护与版本号前缀 `ecom_studio_v1_`），刷新页面不丢失；侧边栏底部提供「恢复默认演示数据」按钮方便重新演示。
4. **轻量 Toast 反馈**：复制文案、导出 PNG、保存模板、导入 CSV 成功或失败时，右上角弹出自动消失的反馈提示。

## 5. 数据结构定义（`src/types.ts`）

```ts
export type VisualStyleId = 'promo-red' | 'minimal-white' | 'luxury-black' | 'fresh-green';
export type CopyTone = 'promo' | 'minimal' | 'lifestyle' | 'professional';

export interface ProductItem {
  id: string;
  name: string;
  category: string;
  material: string;
  specs: string;
  audience: string;
  highlights: string;
  badgeText: string;
  imageUrl: string; // Data URL (上传或内置 SVG Data URL)
  status: 'draft' | 'generating' | 'generated' | 'approved';
  generated?: {
    seoTitle: string;
    posterTitle: string;
    sellingPoints: string[];
    visualStyle: VisualStyleId;
    updatedAt: string;
  };
}

export interface TemplateAsset {
  id: string;
  name: string;
  tags: string[];
  visualStyle: VisualStyleId;
  copyTone: CopyTone;
  badgeDefault: string;
  titleFormulaHint: string;
  description: string;
  createdAt: string;
}

export interface BatchRecord {
  id: string;
  batchName: string;
  createdAt: string;
  status: 'reviewing' | 'completed';
  items: ProductItem[];
}
```

## 7. 执行与验收步骤
1. 初始化 Vite + React + TypeScript + Tailwind CSS 项目结构，安装必要依赖（`lucide-react`）。
2. 按模块拆分实现：`src/types.ts`、`src/data/demoData.ts`、`src/utils/mockGenerator.ts`、`src/utils/canvasRenderer.ts`、`src/utils/csvHelper.ts`、`src/utils/storage.ts` 以及清晰拆分的页面与组件。
3. 编写一份简洁专业的根目录 `README.md`（含本地运行与构建命令）。
4. 运行 `npm run build` 验证编译与类型检查全部通过；若有报错立即修复，直到构建完全成功。
