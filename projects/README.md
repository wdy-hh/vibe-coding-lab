# Projects

这里存放所有实际开发的项目。

每个项目拥有独立的代码、文档、Prompt 和迭代记录。

## 项目列表

[在线演示首页](https://wdy-hh.github.io/vibe-coding-lab/) · [粒子手](https://wdy-hh.github.io/vibe-coding-lab/projects/gesture-particle-system/) · [电商内容工作台](https://wdy-hh.github.io/vibe-coding-lab/projects/ecom-content-studio/)

- [Gesture Particle System](gesture-particle-system/)：用普通摄像头实时识别双手，将掌面与五指转化为可调悬浮外散的 2.5D 粒子结构。当前完成 Phase 2，采用 TypeScript、MediaPipe、Three.js 与 GLSL，提供源码、效果图、完整需求和测试说明。

- [电商内容工作台 · E-Com Studio](ecom-content-studio/)：基于 React 18、TypeScript、Vite 与 Tailwind CSS 的纯前端素材创作工具。支持批量商品录入、模拟内容生成、四套 Canvas 主图风格、800×800 PNG 导出、SEO 文案编辑、模板资产库与历史草稿；所有图片与数据在本地处理，支持离线使用。
