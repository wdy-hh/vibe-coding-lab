运行 `npm run dev`，打开 [合成几何验证页](http://127.0.0.1:5173/tests/browser/surface.html)，点击“运行 GPU 验证”。

1. 双手 20,000 表面粒子、42 高亮点和 4 次绘制。

3. 输入数组换序后画面不变。
4. 显示镜像对称。

## 真实摄像头验收

开发阶段已经运行过 640×480 视频、MediaPipe GPU 和 Three.js WebGL2，并同时识别到两只手。用户反馈“粒子跟随正常”，随后提出外散视觉调整。新增外散已经通过上述 GPU 检查，具体观感可继续用滑块调整。

建议手动检查：

1. 页面加载时不自动打开摄像头；Start 后才申请权限，拒绝时有可恢复提示。
2. 无手、单手、双手分别显示 0、1、2；单手 10,000 + 21 个点，双手 20,000 + 42 个点。
3. 手掌有连续粒子填充，五根手指完整，弯指与平移持续同步。
4. 外散 0 / 65 / 100% 时均保留可辨认手形，悬浮层跟随，关节高亮不飘走。
5. 视频参考、骨骼调试与镜像切换后仍对齐，并且不重启摄像头。
6. 短暂离开后重新入镜，观察身份与采样；完全无手时清空旧结构。
7. Stop 释放摄像头和粒子资源；连续启停及模型加载期间停止不会晚到复活。
8. 进一步观察快速交叉、遮挡、不同光照和长时间运行。

仍需后续测量的项目：持续渲染 FPS、端到端延迟、长时间内存趋势，以及不同浏览器/驱动下的表现。当前没有 60 FPS 保证。完全遮挡或极快跳变时，几何身份匹配可能重新分配 ID。
